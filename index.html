LASCE — Institutional Scientific Web Platform

Visitar Producción

Plataforma web institucional y de datos científicos desarrollada para el Laboratorio de Astrofísica Solar y Clima Espacial de la Universidad de Costa Rica. Provee un portal público bilingüe para la presentación de líneas de investigación, publicaciones científicas, noticias, colaboraciones, instrumentos espaciales y el observatorio de radio ROSAC.

Arquitectura como monorepo pnpm/Turborepo con TypeScript, Next.js 16, React 19, PostgreSQL, Prisma, Redis, BullMQ, MinIO, InfluxDB y un worker en segundo plano en Python 3.13.

Contribuciones clave: Desarrollo integral de la suite CMS para noticias y observatorio ROSAC (flujos de creación, edición, borrado, transacciones Prisma, subida a MinIO y control de concurrencia optimista), estandarización de componentes modales de gestión, accesibilidad WCAG y cobertura automatizada con Playwright E2E y Vitest.

Next.js 16 React 19 TypeScript PostgreSQL / Prisma Redis / BullMQ Python 3.13 Worker Playwright E2E WCAG Accessibility
