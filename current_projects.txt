LASCE — Institutional Scientific Web Platform

LASCE is a full-stack institutional and scientific-data platform developed for the Laboratorio de Astrofísica Solar y Clima Espacial of the University of Costa Rica. The platform provides a bilingual public portal for presenting research areas, scientific publications, news, collaborations, researchers, scientific instruments, space-weather projects, and the ROSAC radio observatory.

The application is implemented as a pnpm and Turborepo monorepo using TypeScript, Next.js 16, React 19, PostgreSQL, Prisma, Redis, BullMQ, MinIO, InfluxDB, and a Python 3.13 background worker. The web application uses Next.js Server Components, Server Actions, route handlers, Zod validation, next-intl, Leaflet maps, Storybook, Vitest, React Testing Library, Playwright, and axe-core. The Python worker uses asyncio, SQLAlchemy, Pydantic, Ruff, mypy, and BullMQ to process scheduled scientific-data jobs and communicate with shared infrastructure.

My contributions focused primarily on the news, publications, research, ROSAC, gallery, and content-management areas. I implemented database-backed news functionality, searchable news exploration, academic activity pages, dedicated news detail views, publication filtering by research group, research-area detail pages, searchable research collaborations, real ROSAC gallery content, and responsive scientific-content layouts.

I also implemented a complete CMS suite for the news and ROSAC areas. This included create, edit, delete, validation, confirmation, discard-change, image-upload, and toast-feedback workflows. The CMS architecture uses reusable editable wrappers, add-item cards, management modals, Server Actions, Prisma transactions, MinIO uploads, permission-aware workflows, and optimistic concurrency patterns. Several ROSAC sections can be managed through edit mode, including observatory characteristics, scientific activities, construction stages, instruments, researchers, and acknowledgement institutions.

A major part of my work was the refactoring and standardization of the application’s creation, edition, confirmation, and deletion modals. I introduced reusable management and confirmation components, improved modal stacking and portal behavior, prevented duplicate submissions, added inline validation and automatic focus handling, standardized destructive-action confirmations, implemented discard-change protection, fixed responsive scrolling issues, and unified user feedback through translated toast notifications.

The project places strong emphasis on accessibility and quality. I added semantic headings, accessible link and button names, image alternative text, keyboard navigation, responsive behavior, WCAG-oriented axe checks, unit tests, Storybook stories, and Playwright end-to-end coverage across desktop and mobile environments.

The platform can be continued by completing persistence for remaining editable sections, finishing the bilingual migration of legacy content, connecting the gallery CMS to PostgreSQL and MinIO, strengthening asset-management safeguards, integrating additional scientific instruments and data products, and expanding administration, audit history, observability, and production data-querying capabilities.
